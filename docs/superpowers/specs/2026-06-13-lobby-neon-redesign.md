# Lobby(랜딩) 페이지 네온 아케이드 리디자인

**날짜:** 2026-06-13
**선정 시안:** v2 네온 아케이드 (`docs/design/v2-neon-arcade.html` — 시안 3종 중 사용자 선택)

## 목표

로비(랜딩) 페이지의 시각 디자인을 "네온 아케이드" 컨셉으로 교체한다.
기능(닉네임 입력, 방 생성, 방 목록 조회/입장, 대기 화면)과 로직은 일절 변경하지 않는다.

## 디자인 토큰

- 배경: `#07070f` + 퍼플/시안 radial glow 2개 + 옅은 그리드 오버레이
- 타이틀: Orbitron 900, 시안→퍼플→핑크 그라데이션 텍스트 + 글로우
- 본문 폰트: Noto Sans KR
- 패널: 반투명 다크(`rgba(17,17,32,.72)`) + 퍼플 보더 + blur(글래스모피즘)
- 주 버튼: 퍼플→핑크 그라데이션 + 글로우
- 방 목록: LIVE 점(그린), 인원수는 시안색 Orbitron, JOIN 버튼은 시안 아웃라인
- 만석 방: opacity 0.35 + 버튼 FULL/비활성

## 적용 범위

| 파일 | 변경 |
|---|---|
| `client/index.html` | 타이틀 "Cloud Hold'em", Google Fonts(Orbitron, Noto Sans KR) 추가 |
| `client/src/index.css` | Vite 템플릿 잔재 제거 → 전역 배경/폰트/그리드 오버레이 |
| `client/src/pages/Lobby.jsx` | 인라인 styles 객체를 네온 아케이드 토큰으로 교체. 대기(카운트다운) 화면 포함 |

게임 화면(`Game.jsx`)은 이번 범위 밖 (기존 다크 테마가 네온 배경과 무난히 어울림).

## 검증

- 로비: 닉네임 입력 → 방 만들기 → 대기 화면 → 4인 입장 → 게임 시작까지 기존 플로우 동작
- Playwright 스크린샷으로 시안과 대조
